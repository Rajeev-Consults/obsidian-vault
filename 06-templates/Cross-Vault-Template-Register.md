## Assessment fields

For each template, record purpose, lifecycle, canonical owner, counterpart, field-by-field differences, common/distinct decision, mobile suitability, client-facing classification, and change/refresh owner.

## Decision rule

- Keep vault-specific templates where purpose or lifecycle differs.
- Align structure only when the same user action and required fields are genuinely shared.
- Use a controlled derivative or link when execution needs only part of a control template.
- Do not copy every template or expose internal-only fields to mobile/client-facing workflows by default.
